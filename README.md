# 📈 DS Roadmap — интерактивный путь в Data Science с нуля

Веб-приложение с дорожной картой по Data Science: от математики и Python до MLOps и трудоустройства. Отмечайте пройденные темы — прогресс автоматически сохраняется в браузере и переживает перезагрузку.

## ✨ Возможности

- 🗺️ **9 этапов роадмапа** — математика → Python → SQL/Pandas → визуализация и EDA → статистика и A/B-тесты → Machine Learning → Deep Learning → MLOps → портфолио и карьера
- 📚 **30 тем и 100+ навыков** с конкретными подпунктами и ссылками на ресурсы
- ✅ **Отслеживание прогресса**: тема автоматически закрывается, когда отмечены все её подпункты (и наоборот)
- 💾 **Автосохранение в localStorage** — прогресс не теряется при перезагрузке
- 📤 **Экспорт / импорт прогресса в JSON** — перенос между устройствами и браузерами
- 📊 **Визуализация прогресса**: кольцо в шапке, полоска у каждого этапа, общая линия роадмапа, счётчики
- 🎉 **Конфетти** при прохождении роадмапа на 100%
- 📱 **Полный адаптив** — от мобильных (320 px) до десктопа, бургер-меню, учёт `prefers-reduced-motion`

## 🚀 Запуск

Нужен только [Node.js](https://nodejs.org/) (для встроенного статического сервера без зависимостей):

```bash
git clone <url-репозитория>
cd ds-roadmap
npm run dev
```

Сервер поднимется на `http://localhost:7100/`. Порт и хост можно переопределить:

```bash
npm run dev -- --port 8080 --host 127.0.0.1
```

Также проект — чистая статика: `index.html` можно открыть напрямую в браузере или раздать любым статическим хостингом (GitHub Pages, Netlify, Vercel).

## 💾 Как хранится прогресс

Прогресс сохраняется в `localStorage` под ключом `ds-roadmap-progress-v1` как плоский объект вида:

```json
{
  "math-linalg": true,
  "math-linalg-s0": true
}
```

Кнопка **⬇ Экспорт** скачивает JSON-файл с прогрессом и датой выгрузки, **⬆ Импорт** — восстанавливает его (с валидацией ключей и восстановлением согласованности «тема ↔ подпункты»). **Сброс** очищает прогресс после подтверждения.

## 🛠️ Как добавить свой этап или тему

Весь контент роадмапа живёт в `js/data.js`. Добавьте объект в массив `ROADMAP`:

```js
{
  id: "my-stage",            // уникальный id этапа
  num: "10",
  title: "Мой этап",
  icon: "🔥",
  color: "#7c5cff",          // акцентный цвет этапа
  duration: "1 месяц",
  level: "Профи",
  desc: "Описание этапа",
  topics: [
    { id: "my-topic", title: "Тема", subs: ["Навык 1", "Навык 2"] }
  ],
  resources: [{ name: "Ссылка", url: "https://..." }]
}
```

UI, прогресс-бары и счётчики перестроятся автоматически.
